Laboratorio de simulación con IA: 20 apps de obligado uso del MBA-UMH

Cada app es un simulador de práctica deliberada vinculado a una asignatura del plan de estudios: genera un caso, sitúa al estudiante en un rol profesional real, le enfrenta a interlocutores de IA y evalúa su desempeño con rúbrica exportable. Todo funciona en el navegador, sin servidor: solo necesitas tu clave de API de OpenAI (botón 🔑 dentro de cada app).

7 asignaturas del módulo común2 optativasPrácticas externasTFMgpt-4o-miniSin backend · GitHub Pages
Cómo se usa en la evaluación continua: el estudiante realiza las sesiones indicadas por cada asignatura, exporta el informe (.md o PDF) con la transcripción y la rúbrica, y lo entrega como evidencia. El historial de sesiones queda guardado en el propio navegador (IndexedDB). La clave de API se almacena solo en localStorage del estudiante y las llamadas van directas a la API de OpenAI.
